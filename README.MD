# Практикум по библиотеке Pandas: Анализ датасета user.csv
### Выполненные задачи
* Загрузка и анализ типов данных: чтение CSV-файла с информацией об учениках, проверка автоматического определения типов (dtype), выявление необходимости ручного преобразования строковых представлений дат.
* Преобразование и работа с датами: конвертация столбцов birthday и last_visited в формат datetime64 с явным указанием шаблонов (%d.%m.%Y и %d.%m.%Y %H:%M:%S), использование аксессора .dt для извлечения месяца и дня.
* Фильтрация и условный отбор:
   * Подсчёт учеников, родившихся в сентябре, через группировку по месяцу и адресацию .loc[9].
   * Выборка учеников, посещавших платформу в первые 14 дней сентября, с помощью комбинированных условий & по .dt.month и .dt.day.
   * Фильтрация регионов по подстроке «город» с предварительным приведением к нижнему регистру (.str.lower().str.contains()).
* Группировка и многомерная агрегация: анализ распределения учеников по классу и полу через .groupby(['grade', 'gender']), расчёт количественных показателей по категориям.
* Работа с пропущенными значениями: выявление некорректного сравнения с np.nan, применение метода .notna() для фильтрации валидных записей, расчёт статистик (среднее, процент 9-классников) на очищенных данных.
* Расчёт производных метрик: вычисление доли учеников 9-х классов от общего числа записей с заполненным классом, округление результатов до целых чисел.
