# Практикум по библиотеке Pandas: Анализ датасета Titanic

## Выполненные задачи
1. **Создание и манипуляция структурами данных**: работа с `pd.Series` и `pd.DataFrame`, создание из списков и словарей, присвоение имен, сортировка по индексу и значениям.
2. **Загрузка и первичный осмотр данных**: чтение csv-файлов из внешних источников, добывание информации, типов данных и базовой статистики.
3. **Исследовательский анализ**:
   - Вычисление минимального, среднего и максимального возраста пассажиров.
   - Анализ распределения по полу и классу обслуживания.
4. **Группировка и агрегация**: расчет среднего возраста в разрезе классов пассажиров.
5. **Слияние таблиц**: объединение таблицы с личными данными пассажиров и таблицы с метками выживаемости по индексному ключу. Предварительная подготовка индексов и перемешивание данных.
6. **Корреляционный анализ**: кодирование категориального признака пола в числовой формат, построение матрицы корреляций между полом, возрастом и фактом выживания. Визуализация матрицы.

## Использованные функции и методы
| Категория | Функции / Методы |
|-----------|------------------|
| **Создание и загрузка** | `pd.Series()`, `pd.DataFrame()`, `pd.read_csv()`, `pd.date_range()` |
| **Индексирование** | `.loc`, `.iloc`, условная фильтрация `df[condition]`, срезы `df[start:stop]`, выбор колонок `df['col']` |
| **Агрегация и статистика** | `.shape`, `.info()`, `.describe()`, `.head()`, `.min()`, `.mean()`, `.max()`, `.sum()`, `.value_counts()` |
| **Группировка и сортировка** | `.groupby()`, `.sort_index()`, `.sort_values()` |
| **Объединение и модификация** | `.join()`, `.sample()`, `np.arange()`, `.astype()`, прямое присваивание колонок `df['new_col'] = ...` |
| **Анализ зависимостей** | `.corr()` |
| **Визуализация** | `sns.heatmap()` (Seaborn) |
